# 📚 Кулинарная книга рецептов горячего копчения

Этот проект представляет собой **локальное веб-приложение для управления кулинарными рецептами**, специализирующееся на рецептах горячего копчения. Система позволяет добавлять, редактировать, просматривать рецепты и автоматически генерировать профессиональные PDF-документы с поддержкой изображений.

Разработано как учебный проект по автоматизации документооборота, но полностью пригодно для личного использования.

---

## 🔥 Основные возможности

- ✅ **Добавление новых рецептов** через удобную веб-форму  
- ✅ **Редактирование существующих рецептов** без ручной работы с CSV  
- ✅ **Автоматическая генерация PDF** с фотографиями, ингредиентами и пошаговыми инструкциями  
- ✅ **Умное форматирование времени подготовки**:  
  `120 мин` → `2 ч`, `1440 мин` → `1 сут.`, `3000 мин` → `2 сут. 2 ч`  
- ✅ **Просмотр списка рецептов** с фото-превью прямо в браузере  
- ✅ **Открытие PDF в новой вкладке** одним кликом  
- ✅ **Резервное копирование** перед любыми изменениями (`recipes.csv.bak`)  
- ✅ **Полностью автономная работа** — не требует интернета или облачных сервисов

## ⚙️ Требования

- Python 3.8+
- Windows / macOS / Linux
- Браузер (Chrome, Firefox, Edge и др.)

### Зависимости
- `flask` — веб-сервер
- `weasyprint` — генерация PDF
- `jinja2` — шаблонизация
- `base64` — встраивание изображений в PDF

📝 Формат данных (CSV)
Файл recipes.csv содержит следующие колонки:
Колонка
Описание
Пример
name
Название рецепта
Свиная грудинка горячего копчения
category
Категория
Горячее копчение
prep_time
Время подготовки (в минутах)
1440
cook_time
Время копчения (в минутах)
90
temp_range
Температурный диапазон
90–110°C
ingredients
Ингредиенты (разделены ;)
Свиная грудинка — 1.5 кг; Соль — 4 ст.л.; ...
instructions
Пошаговый рецепт
1. Натрите грудинку... 2. Выдержите 24 часа...
servings
Порции
6–8 порций
photo
Путь к фото (относительно корня)
photos/pork_belly_smoked.jpg
🖼️ Поддержка изображений
Фотографии хранятся в папке photos/
Поддерживаются форматы: JPG, PNG
Изображения автоматически встраиваются в PDF через Base64 (работает даже при перемещении файла)
Если фото отсутствует — отображается заглушка
🛡️ Безопасность и надёжность
Перед каждым изменением создаётся резервная копия: recipes.csv.bak
Все пути обрабатываются безопасно (защита от инъекций)
Автоматическая очистка недопустимых символов в именах файлов
Защита от двойной генерации PDF
